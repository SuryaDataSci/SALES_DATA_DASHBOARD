# SALES_DATA_DASHBOARD
Created an interactive sales dashboard in Excel, enhanced with AI-powered insights for forecasting and trend analysis. Used pivot tables, slicers, and conditional formatting to organize and present data effectively, ensuring clear and insightful visualizations.
**Key Points for the project:  
 **AI Integration:** Incorporated AI-driven features for forecasting sales trends and predicting future growth patterns.  
 **Data Handling:** Cleaned and organized raw sales data for analysis using advanced Excel tools and Python libraries.  
 **Excel Features:** Utilized pivot tables, slicers, and filters to make data exploration and comparison intuitive and user-friendly.  
 **Data Visualization:** Created dynamic charts and graphs, including bar charts, line graphs, and heatmaps, to display trends and performance metrics clearly.  
 **Conditional Formatting:** Applied conditional formatting to highlight key insights like top-performing products, regions, and sales anomalies.  
 **User-Friendly Design:** Formatted the dashboard for readability with clear headings, color-coded sections, and interactive elements for easy navigation.  
 **Automation:** Streamlined repetitive tasks like data updates and chart refreshes using macros and Python scripts.  
 **Insights Delivered:** Provided insights on sales performance, seasonal trends, and regional analysis to support strategic planning.  
 **Tools & Techniques:** Leveraged Excel functionalities, NumPy, pandas, and matplotlib to ensure a seamless blend of manual and automated analysis.
